# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting or contact a repository maintainer privately. Include reproduction steps and impact, but do not include real employee records, credentials, or other sensitive production data.

## Data handling expectations

- Use synthetic data in development, tests, and examples.
- Keep secrets in an approved secret store or local environment configuration excluded from version control.
- Restrict access to payroll inputs, outputs, and audit records according to organizational policy.
- Treat logs, temporary files, exports, and backups as potentially sensitive.
